# DevSecOps Secure CI/CD Application

A simple Flask-based application demonstrating a DevSecOps-oriented CI/CD workflow.

## Features

- Flask web application
- Health check endpoint
- Git version control
- CI/CD pipeline ready
- Security scanning integration ready

## Application Endpoints

### Home
`/`

Displays the DevSecOps Secure Application page.

### Health Check
`/health`

Returns:

```json
{
  "status": "healthy"
}
